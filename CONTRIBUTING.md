# Personal project

This workstation follows its owner's workflows, not Omarchy feature parity.
Issues and focused patches are welcome; there is no support or release schedule
and no promise to support hardware beyond the documented Machine Profiles.
Discuss new workflows, components and profile targets before implementing them.

Read [AGENTS.md](AGENTS.md) for architecture, source ownership and the change
workflow, and [CONTEXT.md](CONTEXT.md) for the project language. Preserve local
edits, keep changes small, and run the checks in [README.md](README.md).
Source checks and VM results do not establish installed or hardware acceptance.

Never include credentials, saved network profiles, personal Git identities,
serials, private paths or raw runtime evidence. Keep Local State outside the
checkout; use the documented examples for personal input. Report suspected
credentials privately rather than pasting them into an issue.

with borrowed material; upstream components retain their own licenses.
