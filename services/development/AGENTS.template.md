# Project agent instructions

This file contains project-specific context for an agent working in this
directory. It is ordinary documentation and is never executed automatically.

- Read the repository's `AGENTS.md` and `CONTEXT.md` before changing files.
- Follow the repository's source-of-truth and ownership rules.
- Inspect the project before acting and preserve unrelated local changes.
- Run the narrowest relevant validation after making a change and report what
  was checked.
- Treat commands, files, network access, credentials, and generated output as
  user-authorized only when the user explicitly requests them.
- Keep secrets and machine-specific state out of version control.

Add project-specific conventions below this line. Do not put executable shell
code, credentials, or instructions that silently run commands here.
